# 经纬空间开发任务拆分

> 本清单依据 `JINGWEI_SPATIAL_TWIN_MASTER_PLAN.md` 拆分。每轮只实现一个可运行的最小闭环，并执行受影响模块的最小验证。

## M0 文档原型与工程骨架

| 编号 | 最小任务 | 交付与验收 |
|---|---|---|
| M0-01 | Vue 管理端可运行骨架 | 12 个页面路由可导航；中文模拟数据；类型检查和生产构建通过 |
| M0-02 | Spring Boot 3 可启动骨架 | JDK 21；统一响应与健康接口；配置分环境；Maven 编译和最小 HTTP 检查通过 |
| M0-03 | MySQL 8.0 与 Redis 本地环境 | Docker Compose 或明确的本地安装方案；连接配置只读环境变量；连通性检查通过 |
| M0-04 | API 契约与数据库基线 | OpenAPI 基础约定、错误码、初版系统 DDL、Flyway 迁移可执行 |
| M0-05 | M0 联调与验收 | 前后端启动脚本、环境检查、关键页面导航和健康接口形成闭环 |

## M1 注册登录与 RBAC

| 编号 | 最小任务 | 交付与验收 |
|---|---|---|
| M1-01 | 初始化管理员向导 | 仅允许安全初始化；无硬编码默认密码；审计初始化行为 |
| M1-02 | 登录、登出与会话 | Sa-Token + Redis；失败锁定；禁用账号不可登录 |
| M1-03 | 用户、角色、菜单 | MyBatis-Plus 持久化；前后端权限码一致 |
| M1-04 | API 与资源权限 | 注解鉴权、Service 对象级校验、越权用例通过 |
| M1-05 | 安全审计 | 登录、授权、下载、发布和删除等关键行为可追溯 |

## M2 项目与地图标注

| 编号 | 最小任务 | 交付与验收 |
|---|---|---|
| M2-01 | 项目 CRUD | 项目列表、详情、归档和项目级权限闭环 |
| M2-02 | 地图适配层 | `MapAdapter` 模拟实现可运行；高德 Key 存在时启用真实适配器 |
| M2-03 | 默认地图视角 | 保存中心点、缩放、俯仰和园区边界；重开后恢复 |
| M2-04 | 点线面与楼宇轮廓 | CRUD、空间元数据和校验闭环 |
| M2-05 | bbox 视野查询 | 仅返回当前视野对象；权限与索引检查通过 |

## M3 写实楼宇与手动精细加载

- M3-01 Three.js 场景管理与资源释放。
- M3-02 标准写实楼宇模板与质量档位。
- M3-03 楼宇摘要选择，不自动下载高清资源。
- M3-04 主动进入精细模式并支持取消、失败重试和卸载。
- M3-05 GLB 上传、检查、替换与业务对象关系迁移。
- M3-06 性能面板与连续切换稳定性验证。

## M4 楼层空间

- 楼层目录、图纸上传与人工配准。
- 房间区域、部门人数、设备点位和专业图层。
- 未选楼层不下载详情，资源权限由后端强制校验。

## M5 草稿、发布与项目包

- 草稿校验、发布快照、回滚。
- 项目清单与资源包导入导出。
- 跨机器恢复、模型质量警告和审计。

## M6 专业资料

- 基于真实样本分步验证 IFC、DXF、正射影像或 3D Tiles。
- 建立楼层映射、可信度标签、人工校准和导入报告。
- 不在缺少真实样本时承诺自动重建。

## M7 行业扩展

- IoT 接入、更多合法授权地图源、私有化交付和行业模板。
- 以真实客户场景、安全审查和合规要求作为启动条件。
