# spatial-twin-common

后端公共基础模块，只放所有业务模块都会复用、且不表达具体业务含义的代码。

## 当前职责

- 统一接口响应体 `ApiResponse`
- 统一业务错误码与业务异常
- 全局异常转换
- 请求标识处理
- 跨模块统一分页响应
- 跨模块审计记录端口

## 边界

- 可以依赖 Spring Web、参数校验等基础框架。
- 不得出现用户、角色、项目、楼宇等业务实体。
- 不得反向依赖任何 `spatial-twin-module-*` 或 `spatial-twin-server`。
- 新增工具前先确认至少有两个业务模块需要复用，避免把公共模块变成杂物目录。
